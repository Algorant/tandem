## Description

Create the small static semantic inventory that defines implemented actions, fixed bindings, scopes, labels, and input precedence. Use it where practical to drive input dispatch metadata, help, footer/header labels, mouse-equivalent actions, and consistency tests without creating runtime rebinding or a general keymap framework.

Inventory every current global, view, pane, picker, prompt, and mouse action. Remove stale planned commands from the canonical model. Add focused tests for layer precedence, printable prompt ownership, safe unbound keys, and consistency between semantic actions and displayed labels.

Checkpoint acceptance: the final fixed-keymap table and action scopes are represented in code; precedence is explicit; the project builds; focused tests pass; no user-facing key remap is partially exposed without its dependent picker or help surface.
