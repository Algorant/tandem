## Description

Herdr-agent-tree deliberately ignores its local `.tandem/`, so `tandem checkpoint --consolidate --json` fails at `git add -A -- .tandem` with "paths are ignored" and blocks its v0.3.0 release. The native Tandem CLI owns checkpoint semantics; do not duplicate Git logic in extensions/pi-tandem or the plugin. Detect only an owning `.tandem/` that Git intentionally ignores and that has no tracked/indexed files; leave all tracked metadata repositories on the existing flush and consolidation path. For this local-only case, do not force-add ignored files or create a metadata commit. Return a distinct explicit local-only result that still satisfies the push-boundary consolidated success contract (status consolidated with localOnly or equivalent) after the normal upstream, branch, unsafe-history and worktree guards. Preserve ignored bytes and unrelated staged/unstaged/untracked state; fail closed on uncertain Git detection. Document the CLI JSON result and guidance. Algorant explicitly requested a patch-line Tandem release of this fix (v0.14.1 if 0.14.0 is current), not v0.15.0; coordinate release as a separate Task if repository rules require it. The owning desktop Tandem agent should implement, test, push and publish the patch release after review, then advise this orchestrator how to update the x1nano installed CLI safely.
