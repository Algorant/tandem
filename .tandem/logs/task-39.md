Algorant approved closing the remaining gap after Tandem 0.13.4. Version 0.13.4 correctly folds pending `.tandem/` state into any unpushed non-merge real commit and reconciles leftover chores, but that logic only runs at root assignment lifecycle boundaries. `add`, `update`, rule mutations, Epic/Subtask lifecycle, and other intermediate writes can remain dirty indefinitely; ordinary `git commit && git push` does not invoke Tandem. This caused ffsync to push source commits while leaving its events log, a rule, and task-137 uncommitted.

Add one explicit native, idempotent checkpoint/flush operation that invokes the existing 0.13.4 checkpointer without fabricating an Accord or record transition. It is the authoritative integration point for adapters and commit/push workflows. The intended order is: create the real source commit, invoke native flush, verify `.tandem` clean, then push. With an unpushed non-merge real HEAD, the flush amends that commit and preserves its subject. With no absorbable real commit, metadata-only work may use at most one rolling Tandem checkpoint. This Task does not add hooks or Pi code.

This Task includes the complete Tandem release boundary, not only implementation. After the Worker delivery is independently verified and integrated by the Tandem orchestrator, prepare and publish the next Tandem release with its version metadata, annotated Git tag, pushed tag, and GitHub Release. Confirm the release is available through the normal mise source. Do not tell the Pi workspace to begin its consumer implementation merely because source landed on Tandem main; report readiness only after the full release is live. The Pi side will then install it using Algorant's exact `sysup mise` command and verify that the resolved active Tandem binary reports the new version.

Before implementation, the Worker must report a plan/spec for orchestrator approval. It should ask the orchestrator focused questions through `worker_ask` where CLI naming, envelope semantics, or safety behavior is genuinely unclear rather than guessing.
