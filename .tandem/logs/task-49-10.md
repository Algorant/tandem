## Description

Found while verifying the 0.15 candidate for the ~/.pi orchestrator (/tmp/tandem-015-shapes.txt). Sync correctly holds an unparsable record, but ordinary reads and mutations parse every record strictly, so `list` and `add` (also from linked worktrees) fail with `Parse failure` until the file is fixed. The approved design says a held edit stays local while other work continues.
