## Description

Implement `decision-11` in `tandem/src/protocol/` after task-239-1 lands the spec change and task-241 lands the Board affordance.

## Required reading

`decision-11`, then the revised `protocol/plan/spec.md` from task-239-1. The spec is normative; this task follows it.

## Changes

- Remove accord-to-state synchronization for `delivered`, `accepted`, and `rework`. Only `claim` moves state (`todo` to `in-progress`).
- Enforce `review.status: pending` as the only entrance to `validation`, including rejecting a direct `move` to `validation` without one.
- Make review resolution human-only.
- Make `accord rework` clear a pending review.
- Allow review requests independent of accord status, restricted to the delegated Task boundary: reject on Subtasks, exempt Epics.
- Invert completion policy: silent on missing `review.status`, hard error on pending.
- Add or update tests covering every transition above, including the rejection paths.

## Constraints

- Do not change normative semantics here. If the spec is ambiguous, stop and report rather than deciding.
- Route durable mutations through shared `app` operations over `project::TandemProject`.
- `cargo fmt`, `cargo clippy --all-targets -- -D warnings`, and `cargo test` must pass.
