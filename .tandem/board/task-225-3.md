## Description

Replace direct Board hotkey groups with explicit `f`, `m`, and `v` picker surfaces.

The filter picker manages tag and priority filters plus clear-one/clear-all behavior. The move picker lists valid configured target states and uses existing graph-safe app mutation paths. The Validation picker exposes only valid accept, rework, and apply/archive actions and explains unavailable choices.

Use one shared visual and interaction grammar: clear title/context, selectable actions, disabled reasons, standard navigation, Enter activation, Esc cancel, responsive layout, theme styles, footer hints, and keyboard/mouse parity. Preserve Board selection, hierarchy context, and state after apply/cancel.

Checkpoint acceptance: old t/p/F, H/L, and A/R/C actions are removed; f/m/v provide complete replacement flows; mutations remain protocol/app owned; focused behavior, error, cancellation, and mouse tests pass.
