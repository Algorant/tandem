## Description

Replace the current help overlay with a complete, polished, responsive `?` keybinding reference generated from or checked against the canonical semantic binding inventory.

Make it available from Board, Logs, Rules, Decisions, Papercuts, and every non-text picker/dialog. Organize content into Global, Navigation, Current view, Board, Validation, Logs, Rules, Decisions, Utility inbox, Dialogs/text input, and Mouse sections. Prioritize current context while preserving access to the complete map. Add section hierarchy, selected/focused styles, scrolling, narrow/short layouts, mouse wheel/section selection, and a close hit target. Esc restores the exact underlying state; q quits; text prompts retain `?` as text.

Synchronize contextual footers, header hints, `tandem/plan/spec.md`, `tandem/plan/todo.md`, `docs/tui/index.md`, and any required README text.

Checkpoint acceptance: every implemented binding is discoverable; no planned/unimplemented binding appears; help, footer, docs, and dispatch consistency tests pass; the reference is legible and unclipped in supported layouts and themes.
